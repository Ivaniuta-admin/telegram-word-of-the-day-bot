# Woord van de dag — Telegram-бот для мовного курсу

Бот для курсу нідерландської мови: у дні занять надсилає в групи студентів «слово дня» з перекладом, прикладом і аудіо вимови, а також нагадування про урок. Один бот обслуговує кілька груп, у кожної свій розклад, рівень і черга слів.

> Це вітринна копія робочого проєкту, який щодня працює для реального курсу (7 груп рівнів A1/A2). Тут немає реальних чатів, посилань на зустрічі, матеріалів курсу й аудіо: словник містить 5 прикладів, а групи вигадані.

## Що вміє

- **Слово дня** о 10:00 за Києвом у дні занять групи: слово, переклад, приклад, назва уроку й аудіо з вимовою (якщо аудіо немає, слово йде текстом).
- **Нагадування про урок** вранці й за годину до початку, з посиланням на онлайн-зустріч.
- **Кілька груп** в одному боті: розклад, дата старту, словник і черга слів задаються для кожної групи окремо в `courses.json`.
- **Винятки в розкладі:** перенесений урок задається датою в `special_lesson_times`.
- **Ізоляція помилок:** збій в одній групі не зупиняє розсилку в інших.
- **Тестовий запуск** з кнопки Run workflow з галочкою force: надсилає одразу, ігноруючи дату й день тижня.

Приклад повідомлення:

```
🌷 Woord van de dag

🇳🇱 Слово:
de fiets

🇺🇦 Переклад:
велосипед

💬 Приклад:
Ik ga met de fiets naar mijn werk.

📚 Урок: Les 1 — Kennismaken
```

## Як влаштовано

| Файл | Що всередині |
| --- | --- |
| `run_daily.py` | Логіка: які групи сьогодні вчаться, яке слово наступне, що й коли надсилати |
| `courses.json` | Групи: розклад, дата старту, словник, змінні з chat ID |
| `words.csv` | Словник: урок, слово, переклад, приклад, назва аудіофайлу |
| `.github/workflows/woord-van-de-dag.yml` | Запуск і збереження черги слів (state-файли) назад у репозиторій |

Бот не потребує сервера. Вбудований cron GitHub Actions на практиці запізнювався на години, тому workflow запускається зовнішнім планувальником (cron-job.org) через `workflow_dispatch` у потрібні моменти: о 10:00 ранковий блок і за годину до початку кожного уроку.

Нові слова й уроки викладач додає сам: рядки в CSV + аудіофайли в `audio/`, без зміни коду.

## Запуск

1. Створіть бота в @BotFather і додайте його в групи як адміністратора.
2. Settings → Secrets and variables → Actions: `TELEGRAM_BOT_TOKEN` і chat ID кожної групи (`TELEGRAM_GROUP1_CHAT_ID`, `TELEGRAM_GROUP2_CHAT_ID`).
3. Налаштуйте групи в `courses.json` і словник у `words.csv`.
4. Перевірте: Actions → Woord van de dag → Run workflow з галочкою force.
5. Для автозапуску налаштуйте виклики `workflow_dispatch` у cron-job.org або поверніть блок `schedule` у workflow.
